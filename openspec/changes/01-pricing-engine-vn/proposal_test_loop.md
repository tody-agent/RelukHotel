# Proposal: Tự động hóa Test & Quality Gate (Dự án CapyInn)
Generated by: cm-brainstorm-idea

## Why we're doing this
### Qualified Problem
**For:** Đội ngũ phát triển & AI Agents làm việc trên dự án CapyInn.
**Who:** Cần đảm bảo chất lượng code sau mỗi lần thay đổi (thêm, sửa, xóa).
**The:** Quy trình phát triển hiện tại
**That:** Cần tự động bắt buộc cập nhật test, vượt qua test gate trước khi deploy, và có cơ chế tự sửa lỗi (auto-fix) nếu test fail.
**Unlike:** Các kỹ năng toàn cục (CodyMaster kit) áp dụng chung cho mọi dự án, cơ chế này chỉ được giới hạn (scoped) và cấu hình riêng cho CapyInn.
**Our approach:** Xây dựng một quy trình khép kín tại local project (Local AI Rules + Git Hooks + Orchestrator loop).

### Root Cause(s):
1. **Technical:** AI agents đôi khi sẽ lười hoặc bỏ quên việc viết test nếu không có System Prompt/Manifest nội bộ nhắc nhở liên tục.
2. **Process:** Chưa có chốt chặn cứng (Hard Gate) khi thực hiện git push hoặc chuyển tiếp sang deploy.

| **Components** | Không có rule rõ ràng cho AI | Agent Prompt rời rạc | `AGENTS.md` + `pre-push` hook + Vòng lặp Orchestrator |

## What's changing
### Options Evaluated

**Option A: Project-Local AI Manifest & Git Hooks (Khuyên dùng)**
- **Approach:** Tạo file `AGENTS.md` (hoặc `.cursorrules`) tại thư mục gốc CapyInn, quy định bắt buộc AI phải tuân thủ luồng: Code -> Update Test -> Chạy `test_gate.sh` -> Đọc log -> Fix. Đồng thời cài đặt `pre-push` git hook để chặn deploy nếu test gate fail.
- **Effort:** Small (~30 mins)
- **Pros:** Đơn giản, scoped 100% trong CapyInn, mọi AI Agent (Claude, Cursor, Antigravity) đều đọc được.

**Option B: Nâng cấp `autopilot_orchestrator.py` thành Self-healing Loop**
- **Approach:** Viết thêm logic vào file Python để sau khi agent trả code, Python tự chạy `test_gate.sh`. Nếu exit code != 0, Python tự tạo một prompt mới kèm theo error log gởi lại cho Webhook để agent tự sửa.
- **Effort:** Medium (~2 hours)
- **Pros:** Tự động hoàn toàn trong lúc ngủ.
- **Cons:** Phức tạp hóa file Python hiện tại, khó debug nếu agent loop vô tận.

### Recommendation
**Chọn Option A (kết hợp một phần Option B)**
Chúng ta sẽ:
1. Tạo file `AGENTS.md` tại gốc `CapyInn/` chứa quy tắc TDD và Auto-fix.
2. Sửa prompt trong `autopilot_orchestrator.py` để nhúng rule này vào mỗi task.
3. Cài đặt Git hook `pre-push` gọi `test_gate.sh`.

Bằng cách này, chúng ta định hình lại tư duy của AI khi làm việc riêng cho repo CapyInn mà không chạm đến bộ CodyMaster gốc.
