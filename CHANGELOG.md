# Changelog

All notable changes to this project will be documented in this file.

- Dynamic pricing rules (weekend/holiday/specific-date overlays)
- Real-time pricing preview in check-in and check-out dialogs

- open-source repository metadata and community files
- CI workflow and GitHub issue / PR templates
